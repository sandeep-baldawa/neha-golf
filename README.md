# Neha Baldawa Golf Profile — Version 1

This is a static recruiting website starter.

## Files
- `index.html` — page structure and content
- `styles.css` — visual design
- `script.js` — tournament results and upcoming schedule

## Fastest way to preview
Open `index.html` in a browser.

## Publishing options
This can be deployed free on:
- GitHub Pages
- Netlify
- Vercel
- Cloudflare Pages

## Before publishing
Please verify:
1. Every tournament result and date
2. Current JGS/TUGR ranking and profile URLs
3. GPA and academic details
4. Recruiting email
5. Swing / short-game video links
6. Whether you want Foothill High School and Pleasanton shown publicly

For a minor, avoid publishing a home address, personal phone number, or private schedule details beyond tournament information.

## Updating scores
Open `script.js` and add a new object near the top of the `results` array:
`{date:"2026-08-30", event:"Baylands", tour:"U.S. Kids", score:"79", notes:"Tour Championship"}`

The newest result should stay at the top.
